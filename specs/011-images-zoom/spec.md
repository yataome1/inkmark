# 功能规格：图片统一存放与缩放记忆

**特性分支**: `011-images-zoom` | **创建日期**: 2026-11-10 | **状态**: 已批准（2026-11-10 增补用户故事 7）
**输入**: 为确保移动 Markdown 文件后图片不丢失（用户往往不会同时移动图片），粘贴的图片不再保存到文档同目录的 `assets` 文件夹，统一存放在 `C:/Users/用户名/AppData/Local/inkmark-images/`；可设置图片文件夹位置，换电脑后能自动找到图片；需要分享时可导出带图片的副本；收到副本或打开旧文档时，可把文档旁的图片收入图片文件夹；增加 `Ctrl+鼠标滚轮` 缩放；保存缩放比例，下次打开时沿用。

## 用户场景与测试

### 用户故事 1 —— 移动文档后图片仍然显示 (P1)

用户粘贴或拖入图片后，把 Markdown 文件移动或复制到其他目录，图片仍然正常显示。

**独立测试**：在文档中粘贴图片并保存，把文档移动到另一个目录后重新打开。

**验收场景**

1. **当** 在任何文档（已保存或未命名）中粘贴或拖入图片，**那么** 图片保存到图片文件夹（默认 `%LOCALAPPDATA%\inkmark-images\`），文档中插入该图片的绝对路径。
2. **当** 保存图片，**那么** 文件名由图片内容生成（内容哈希加原扩展名）；同一张图片多次粘贴只保存一份，不同图片不会互相覆盖。
3. **假设** 文档已插入这类图片，**当** 把文档移动或复制到其他目录后打开，**那么** 图片正常显示。
4. **假设** 旧文档引用 `assets/` 下的相对路径图片，**当** 打开，**那么** 照常显示，文档内容不被修改。
5. **当** 导出含这类图片的 HTML 或 PDF，**那么** 图片正常显示。
6. **当** 文档中插入图片，**那么** 该图片文件立即写入磁盘，与文档是否保存无关。

### 用户故事 2 —— 换电脑后自动找到图片 (P1)

用户把图片文件夹放在同步盘（如 OneDrive）或拷贝到新电脑，在新电脑上设置同一个文件夹后，旧文档里的图片能自动显示。

**独立测试**：在一台电脑（或一个 Windows 用户）下插入图片，把文档和图片文件夹拷到另一台电脑（或另一个用户）的不同位置，设置图片文件夹后打开文档。

**验收场景**

1. **假设** 文档中图片的绝对路径在本机不存在，且文件名是 Inkmark 生成的内容哈希名，**当** 打开文档，**那么** 在当前图片文件夹中按文件名查找，找到后正常显示。
2. **假设** 按上述方式找到了图片，**当** 显示，**那么** 不修改文档内容；文档仍保留原路径，不出现未保存标记。
3. **假设** 图片文件名不是 Inkmark 生成的哈希名，**当** 原路径不存在，**那么** 不在图片文件夹中查找，按图片丢失显示，避免误认同名的其他图片。
4. **当** 导出 HTML 或 PDF，**那么** 按同样的规则找到图片。

### 用户故事 3 —— 设置图片文件夹位置 (P1)

用户可以把图片文件夹放到任意位置，例如同步盘或数据盘。

**独立测试**：通过菜单更改图片文件夹，分别选择复制与不复制已有图片，再粘贴新图片。

**验收场景**

1. **当** 选择“文件 → 图片文件夹…”，**那么** 显示当前位置，并可以选择新的文件夹、打开当前文件夹、恢复默认位置。
2. **假设** 原文件夹中已有图片，**当** 更改到新位置，**那么** 询问是否把已有图片复制到新位置；选择复制时逐个复制，新位置已有同名文件时跳过；原文件夹中的图片保留不删。
3. **当** 更改完成，**那么** 之后粘贴的图片保存到新位置，设置在重启后保持。
4. **假设** 新位置无法写入，**当** 确认更改，**那么** 提示原因，设置保持不变。
5. **假设** 设置的文件夹在启动时不存在（如同步盘未挂载），**当** 粘贴图片，**那么** 提示文件夹不可用，不插入图片链接，也不改动设置。

### 用户故事 4 —— 导出可分享副本 (P2)

用户需要把文档发给别人或放到其他电脑时，可以得到一份自带图片、放在任何地方都能显示的副本。

**独立测试**：对含统一存放图片、`assets/` 相对路径图片和网络图片的文档导出副本，把副本文件夹拷到另一台电脑打开。

**验收场景**

1. **当** 选择“文件 → 导出 → 可分享副本…”并选择目标位置，**那么** 生成文档副本，并把它引用的本地图片复制到副本旁的 `文件名.assets\` 文件夹，副本中的链接改为相对路径。
2. **当** 导出完成，**那么** 原文档内容和打开状态不变，状态栏提示复制的图片数量。
3. **假设** 文档引用网络图片，**当** 导出，**那么** 保留原链接，不下载。
4. **假设** 某张本地图片找不到，**当** 导出，**那么** 保留原链接，导出完成后提示缺失的图片数量。
5. **假设** 目标位置已有同名文档或图片文件夹，**当** 导出，**那么** 先询问是否覆盖。

### 用户故事 7 —— 收入图片文件夹 (P2)

用户收到别人导出的副本，或打开图片放在 `assets/` 里的旧文档时，可以把这些图片收进自己的图片文件夹，之后单独移动文档也不会丢图片。

**独立测试**：打开一份带 `文件名.assets\` 的副本和一份引用 `assets/` 图片的旧文档，分别执行收入，保存后把文档单独移动到其他目录再打开。

**验收场景**

1. **当** 选择“文件 → 收入图片文件夹”，**那么** 文档引用的、不在图片文件夹中的本地图片（相对路径或其他位置的绝对路径）按内容哈希复制到图片文件夹，文档中的地址改为新的绝对路径。
2. **假设** 图片文件夹中已有相同内容的图片，**当** 收入，**那么** 不重复保存，直接引用已有文件。
3. **当** 收入完成，**那么** 地址的改动作为一次编辑，可以一步撤销；文档显示未保存标记，由用户决定是否保存。
4. **当** 收入完成，**那么** 原图片文件和文件夹保留不删；状态栏提示收入、已存在和缺失的数量。
5. **假设** 文档没有需要收入的图片，**当** 执行该命令，**那么** 提示“没有需要收入的图片”，文档不变。
6. **假设** 某张图片找不到，**当** 收入，**那么** 保留原地址，计入缺失数量。
7. **假设** 当前是起始页，**当** 查看菜单，**那么** 该命令不可用。

### 用户故事 5 —— Ctrl+滚轮缩放 (P1)

用户按住 `Ctrl` 滚动鼠标滚轮即可放大、缩小界面，与浏览器和多数编辑器的习惯一致。

**独立测试**：在编辑区、侧边栏、标签栏、起始页分别按住 `Ctrl` 上下滚动滚轮。

**验收场景**

1. **当** 按住 `Ctrl` 向上滚动滚轮，**那么** 放大一档（10%）；向下滚动则缩小一档。
2. **假设** 已达到上限 300% 或下限 50%，**当** 继续滚动，**那么** 保持在上限或下限。范围与现有缩放命令一致。
3. **当** 按住 `Ctrl` 滚动，**那么** 编辑区不随之滚动。
4. **假设** 使用高精度滚轮或触控板，**当** 小幅滚动，**那么** 累计到相当于一档普通滚轮的距离才缩放一档，不会一下跳很多档。
5. **当** 查看键盘快捷键列表（`F1`），**那么** 包含“Ctrl+滚轮：放大 / 缩小”。

### 用户故事 6 —— 记住缩放比例 (P2)

用户调整过缩放后，下次打开程序时沿用上次的比例。

**独立测试**：缩放到 130%，退出后重新启动；再按 `Ctrl+Shift+9` 复位后重启。

**验收场景**

1. **当** 通过任意方式（菜单、快捷键、Ctrl+滚轮）改变缩放，**那么** 缩放比例立即保存。
2. **当** 启动程序，**那么** 按上次保存的比例显示。
3. **当** 按 `Ctrl+Shift+9` 恢复实际大小，**那么** 下次启动按 100% 显示。
4. **假设** 保存的比例无效或超出范围，**当** 启动，**那么** 按 100% 显示。

### 边界情况

- 图片文件夹不存在：首次保存图片时自动创建（默认位置）；用户设置的位置不存在时按用户故事 3 场景 5 处理。
- 图片文件夹无法写入：提示保存失败，不插入图片链接。
- 窗口缩放与系统 DPI 缩放相互独立，本功能只调整 Inkmark 自身的缩放。
- 自动查找只在图片文件夹顶层按文件名查找，不搜索子文件夹。

## 需求

### 功能需求

- **FR-1101** 粘贴或拖入的图片必须保存到图片文件夹，以绝对路径插入文档；不再写入文档同目录的 `assets/`。取代 FR-011 中保存到 `./assets/` 的规定。
- **FR-1102** 图片文件名必须由图片内容生成（内容哈希加原扩展名），相同内容只保存一份。
- **FR-1103** 已有文档中的相对路径图片必须照常显示，不自动迁移、不改写文档。
- **FR-1104** 图片的绝对路径不存在且文件名为内容哈希名时，必须在当前图片文件夹中按文件名查找；显示与导出 HTML、PDF 都适用；不修改文档。
- **FR-1105** 必须提供“图片文件夹”设置：查看、更改、打开、恢复默认；更改时可选择复制已有图片；设置持久保存。
- **FR-1106** 必须提供“导出 → 可分享副本”：复制文档与其引用的本地图片，图片放入 `文件名.assets\` 并改为相对路径，不修改原文档。
- **FR-1107** 按住 `Ctrl` 滚动鼠标滚轮必须按 10% 一档缩放，范围 50%–300%，并阻止编辑区随之滚动。
- **FR-1108** 缩放比例必须在每次改变时保存，启动时恢复；无效值按 100% 处理。
- **FR-1109** 键盘快捷键列表必须包含 Ctrl+滚轮缩放。
- **FR-1110** 必须提供“收入图片文件夹”：把文档引用的、不在图片文件夹中的本地图片按内容哈希复制进图片文件夹，并把地址改为绝对路径；改动可一步撤销，不自动保存，不删除原图片。只通过菜单触发，打开文档时不主动提示。

### 非功能需求

- **NFR-1101** 不新增依赖；asset 协议只授权图片文件夹与已打开文档的目录（宪章 V）。
- **NFR-1102** 自动查找不明显拖慢文档打开：只在原路径不存在时查找，且只检查单个文件是否存在。

### 关键实体

- **图片文件夹**：存放粘贴图片的位置，默认 `%LOCALAPPDATA%\inkmark-images\`，可设置。
- **内容哈希名**：由图片内容计算的固定长度十六进制文件名，跨电脑不变，用于自动查找。

## 成功标准

- **SC-001** 用户故事 1–7 的验收场景全部通过。

## 澄清与假设

统一存放的代价与应对：

| 影响 | 应对 |
|---|---|
| 换电脑后路径不同 | 自动查找（用户故事 2）；把图片文件夹设到同步盘可免去拷贝 |
| 发给别人或在其他软件中打开 | 导出可分享副本（用户故事 4），或导出 HTML、PDF；对方用“收入图片文件夹”（用户故事 7）收进自己的图片文件夹 |
| 路径中包含 Windows 用户名 | 分享时使用可分享副本，副本中为相对路径 |
| 删除或忘记备份图片文件夹会导致图片丢失 | 设置界面显示位置并可直接打开；备份文档时需同时备份该文件夹 |

- 未命名文档原来把图片存在系统临时目录（可能被 Windows 存储感知自动清理），改为图片文件夹后不再有此风险。
- 已有 `assets/` 图片不自动迁移，可用“收入图片文件夹”按文档逐个迁移。
- 不在本规格范围：清理不再被引用的图片（下一个规格单独处理）、把自动查找到的新路径写回文档。
