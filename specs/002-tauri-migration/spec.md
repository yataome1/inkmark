# 功能规格：轻量化 —— 安装包降到 10MB 以下

**特性分支**: `002-tauri-migration` | **创建日期**: 2026-11-06 | **状态**: 已实现（0.2.0）
**输入**: “为什么产物的大小有 100 多 MB 呢，我本以为是 10MB 以下的工具。”

## 背景

Inkmark 0.1.0 的安装包约 120MB（解压后约 379MB），其中 95% 以上来自应用自带的 Chromium 浏览器内核与 50 多种语言包，Inkmark 自身代码不到 0.1MB。对于一个 Markdown 查看/编辑工具，用户期望的是 10MB 以下、下载即用的小工具。

Windows 11 已内置浏览器内核（WebView2）。本特性让 Inkmark 改为复用系统内核，并去掉不需要的渲染资源，在**不减少任何 0.1.0 功能**的前提下把体积降到 10MB 以下。

## 用户场景与测试

### 用户故事 1 —— 下载一个小巧的安装包 (P1)
作为用户，我从 Releases 下载 Inkmark，安装包小于 10MB，几秒内下载完成并安装。

**独立测试**：构建产物的文件大小。

**验收场景**
1. **当** 构建发布版本，**那么** 安装包（`Inkmark-Setup-x.y.z-x64.exe`）≤ 10MB。
2. **当** 构建发布版本，**那么** 免安装版（单个 `Inkmark.exe`）≤ 15MB。
3. **假设** 一台干净的 Windows 11 x64，**当** 运行安装包，**那么** 安装完成后可以双击 `.md` 用 Inkmark 打开，无需另外安装任何运行库。

### 用户故事 2 —— 功能与 0.1.0 完全一致 (P1)
作为 0.1.0 的用户，升级后所有功能、快捷键与使用方式不变。

**独立测试**：对新版本重新执行 [001 的全部验收场景](../001-inkmark-mvp/spec.md)。

**验收场景**
1. **当** 按 001 的 `checklist.md` 逐条验证，**那么** 所有之前通过的场景仍然通过，未验证（⏳）的场景至少不比 0.1.0 差。
2. **当** 打开 `resources/samples/demo.md`，**那么** 渲染效果与 0.1.0 一致（标题、列表、表格、代码高亮、KaTeX 公式、Mermaid 图、本地图片、脚注、目录）。
3. **当** 从 0.1.0 升级，**那么** 主题和最近打开文件等设置被保留。

### 用户故事 3 —— 启动快、资源占用不变差 (P2)
**验收场景**
1. **当** 冷启动打开 `demo.md`，**那么** 到可编辑的时间 ≤ 0.1.0（目标 < 2 秒）。
2. **当** 打开 `demo.md` 空闲时，**那么** 内存占用（所有相关进程私有内存合计）不高于 0.1.0 的 120%。

### 边界情况
- 系统缺少 WebView2（如精简版系统、Windows 10 LTSC）：安装程序应检测到并引导下载安装，而不是安装后无法启动。
- 文档中使用 0.1.0 本就不支持的图表语法（ECharts、Graphviz、思维导图、五线谱、PlantUML 等）：仍作为代码块显示，与 0.1.0 一致。
- 文档位于任意磁盘位置（包括其他盘、网络共享目录）：相对路径图片仍能显示。

## 需求

### 功能需求
- **FR-101** 继承 001 的 FR-001 至 FR-017，行为与快捷键不变。
- **FR-102**（替代 FR-018）提供 Windows x64 安装包（注册 `.md` 文件关联、缺少 WebView2 时自动引导安装）与免安装版单文件 exe。
- **FR-103** 只随包分发 001 所需的渲染能力：Markdown 解析、KaTeX、Mermaid、流程图（flowchart.js）、代码高亮、中文界面文本。
- **FR-104** 保留 0.1.0 的用户设置（主题、最近文件、侧边栏状态、最近打开的文件夹）。

### 非功能需求
- **NFR-101** 安装包 ≤ 10MB；免安装版 ≤ 15MB。CI 构建超过上限时失败。
- **NFR-102** 冷启动到可编辑 < 2 秒；打开 `demo.md` 空闲时内存不高于 0.1.0 的 120%（0.1.0 实测 353MB，上限约 424MB；见 [research.md](research.md)）。
- **NFR-103** 继续满足宪章第 II 条（离线）与第 V 条（安全默认）。
- **NFR-104** 构建环境：Windows 11 x64 + Rust stable（MSVC）+ Node.js；CI 可复现构建。

### 关键实体
无新增；Document 与 Settings 同 001。

## 成功标准
- **SC-101** 发布的安装包 ≤ 10MB。
- **SC-102** 001 的验收清单在新版本上全部通过（⏳ 项除外）。

## 澄清与假设
- 运行依赖系统的 WebView2：Windows 11 均已内置；该依赖可以接受。
- 0.1.0 中由 Electron 提供、新平台没有现成对应的能力（页内查找、打印为 PDF、菜单只显示快捷键而不注册），在 plan 中给出等价实现；用户可见行为必须保持不变。
- 不新增任何功能；不改界面设计。
- 版本号升为 0.2.0。
