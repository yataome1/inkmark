# 功能规格：编辑区图片的右键菜单

**特性分支**: `012-image-menu` | **创建日期**: 2026-11-10 | **状态**: 已批准
**输入**: 右键编辑区中的图片时，出现了浏览器内核自带的菜单（将图像另存为、复制图像、复制图像链接、更多工具 → 放大图像、共享），其中“共享”等项与 Inkmark 无关。请为编辑区图片做 Inkmark 自己的右键菜单。

## 用户场景与测试

### 用户故事 1 —— 图片右键菜单 (P1)

用户右键编辑区中的图片，看到与 Inkmark 功能相符的操作，不再出现浏览器内核的菜单。

**独立测试**：在即时渲染模式下，分别右键本地图片、图片文件夹中的图片、找不到的图片和网络图片，逐项执行菜单命令。

**验收场景**

1. **当** 右键编辑区中显示的图片，**那么** 显示 Inkmark 的菜单：复制图片、复制图片文件、图片另存为…、复制图片地址、在资源管理器中显示、用默认程序打开；不出现“复制图像链接”“放大图像”“共享”等浏览器菜单项。
2. **当** 选择“复制图片”，**那么** 图片的画面写入剪贴板（PNG），可以粘贴到聊天软件、Office、画图等程序中；动态 GIF 只复制第一帧。
3. **当** 选择“复制图片文件”，**那么** 剪贴板中放入图片文件本身，与在资源管理器中复制该文件相同：粘贴到资源管理器得到原样的文件；粘贴到 Inkmark 文档中插入原格式的图片，动态 GIF 保留动画。
4. **当** 选择“图片另存为…”，**那么** 打开保存对话框，默认文件名为原文件名，保存后得到与原图相同的文件。
5. **当** 选择“复制图片地址”，**那么** 剪贴板中是文档里写的地址（如 `assets/a.png` 或 `file:///…`），而不是程序内部地址。
6. **当** 选择“在资源管理器中显示”，**那么** 打开图片所在文件夹并选中该图片。
7. **当** 选择“用默认程序打开”，**那么** 用系统中关联的图片程序打开该图片。
8. **假设** 图片找不到（显示为损坏），**当** 右键，**那么** 只有“复制图片地址”可用，其余项灰显。
9. **假设** 是网络图片，**当** 右键，**那么** 只有“复制图片地址”可用；Inkmark 不为此发起网络请求。
10. **假设** 图片是通过自动查找找到的（规格 011），**当** 执行复制、复制文件、另存为、在资源管理器中显示、用默认程序打开，**那么** 作用于实际找到的文件。
11. **当** 菜单打开时按 `Esc` 或单击其他位置，**那么** 菜单关闭，文档不变；可用方向键与 `Enter` 选择菜单项。

### 边界情况

- 编辑区中的文字、链接仍使用系统默认的右键菜单（剪切、复制、粘贴、拼写建议等），不受影响。
- 源代码模式下不显示图片，右键时为文字的默认菜单。
- 右键图片不改变光标位置，也不展开图片的 Markdown 源码。
- “复制图片”复制非 PNG 格式的图片（JPG、GIF、WebP 等）时，剪贴板中为 PNG 图像，画面不变；动态 GIF 只有第一帧；SVG 按显示尺寸转换为位图。需要原文件时使用“复制图片文件”。
- 另存为的目标与原图相同：不做任何操作。

## 需求

### 功能需求

- **FR-1201** 右键编辑区中渲染的图片时，必须阻止浏览器内核的默认菜单，显示 Inkmark 的图片菜单（与表格、文件树使用同一种菜单样式与键盘操作）。
- **FR-1202** 菜单项：复制图片、复制图片文件、图片另存为…、复制图片地址、在资源管理器中显示、用默认程序打开；根据图片是否为本地文件、能否找到，启用或禁用各项。
- **FR-1203** 所有针对文件的操作必须作用于解析后的实际文件（含规格 011 的自动查找），且只接受图片文件。
- **FR-1204** 不改变其他位置的右键菜单。（已由 [014](../014-context-menus/spec.md) 的 FR-1401 取代：所有位置统一使用 Inkmark 菜单）

### 非功能需求

- **NFR-1201** 不新增依赖；不新增前端权限（宪章 V）；不发起网络请求（宪章 II）。

## 成功标准

- **SC-001** 验收场景 1–11 全部通过。

## 澄清与假设

- 已实测（2026-11-10）：在资源管理器中复制 GIF 文件后在 Inkmark 中粘贴，插入的是逐字节相同的原 GIF。

- 浏览器内核默认菜单中的“放大图像”显示的快捷键为“Ctrl，Ctrl”，属于内核行为，替换菜单后不再出现。
- 不在本规格范围：图片缩放与对齐等编辑功能、表格单元格中图片的右键菜单、为网络图片提供下载。
