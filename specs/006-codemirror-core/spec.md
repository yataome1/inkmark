# 功能规格：编辑器内核替换为 CodeMirror 6

**特性分支**: `006-codemirror-core` | **创建日期**: 2026-11-06 | **状态**: 评审中
**输入**: 规格 005 的评估结论（[research.md](../005-editor-core/research.md)）：采用 CodeMirror 6 替换 Vditor，解决撤销整篇重绘、点击跳动、打开即改写文件的问题。

## 用户场景与测试

### 用户故事 1 —— 撤销/重做即时且只影响改动处 (P1)
作为用户，我在长文档中按 `Ctrl+Z` / `Ctrl+Y` 时立即生效，屏幕上其他内容不闪烁、不跳动。

**独立测试**：在约 1150 行、含 15 个 Mermaid 图与 15 个表格的文档中输入、删除、粘贴、表格内修改后逐步撤销与重做，测量耗时并比对其他块的 DOM 节点。

**验收场景**
1. **假设** 在长文档中输入了一段文字，**当** 按 `Ctrl+Z`，**那么** 文字恢复为输入前，耗时 < 16ms，屏幕上其他图表、公式、表格不重新渲染。
2. **当** 连续输入一句话后撤销，**那么** 按自然的输入分组撤销（不是一次撤销一个字）。
3. **当** 撤销，**那么** 光标回到被撤销的位置，滚动位置只在光标不可见时改变。
4. **当** 粘贴、拖入图片、格式快捷键（如 `Ctrl+B`）、查找替换、全部替换之后撤销，**那么** 各自作为一步撤销。
5. **当** 打开另一个文件，**那么** 撤销历史清空，不会撤销到上一个文件的内容。

### 用户故事 2 —— 不改写用户的文件 (P1)
作为用户，我只改了一个字就保存，文件中只有这个字发生变化；打开后不编辑直接保存，文件与原来完全相同。

**独立测试**：对 `resources/samples/demo.md`、长文档、CRLF 换行文件、带 BOM 的文件，分别“打开 → 保存”与“打开 → 改一个字 → 保存”，逐字节比较。

**验收场景**
1. **当** 打开后不编辑直接保存，**那么** 文件逐字节不变（包括 `[TOC]`、任务列表 `[x]`、列表符号、表格空格、空行、转义字符、HTML、末尾换行）。
2. **当** 改动一处后保存，**那么** 文件中只有改动处不同。
3. **假设** 文件使用 CRLF 换行或带 UTF-8 BOM，**当** 保存，**那么** 保持原有换行符与 BOM；新建文件使用 LF、无 BOM。
4. **当** 在源代码模式与即时渲染模式之间切换，**那么** 文本不发生任何变化。

### 用户故事 3 —— Typora 式即时渲染 (P1)
作为用户，我像在 Typora 中一样编辑：内容按排版显示，光标所在元素显示 Markdown 标记，离开后隐藏。

**独立测试**：打开 `resources/samples/demo.md`，逐个元素把光标移入、移出，对照 0.2.1 的显示。

**验收场景**
1. **当** 光标不在某元素内，**那么** 标题、粗体、斜体、删除线、行内代码、==高亮==、链接、图片、行内与块公式、Mermaid 图表、表格、任务列表、引用、列表、分隔线、脚注、`[TOC]`、代码块（高亮）、HTML（如 `<u>`）按排版显示，不显示 Markdown 标记。
2. **当** 光标进入行内元素（粗体、链接、行内代码、行内公式、图片等），**那么** 显示该元素的 Markdown 标记，离开后恢复排版显示。
3. **当** 光标进入图表、块公式或代码块，**那么** 显示其源码，渲染结果保留在源码下方并随输入实时更新。
4. **当** 光标进入表格，**那么** 表格仍按表格显示，可直接编辑单元格文字（表格结构操作见规格 003）。
5. **当** 输入 Markdown 语法（如行首 `## `、`**文字**`），**那么** 立即按排版显示。
6. **当** 按 `Ctrl+/`，**那么** 切换为纯文本源代码模式（不显示任何排版），再按返回即时渲染；光标位置保持。
7. **当** 按住 `Ctrl` 单击链接，**那么** 用系统浏览器打开（仅 http/https）。
8. **当** 使用中文输入法输入（含候选词、组合中按 `Esc` 取消），**那么** 输入正常，组合过程中不闪烁、不提前排版、候选框位置正确。

### 用户故事 4 —— 点击或移动光标时内容不跳动 (P1)
作为用户，我点击图表、公式、图片或用方向键移入、移出它们时，被点击或光标所在处的内容保持在原来的屏幕位置。

**独立测试**：同规格 003 用户故事 4（真实鼠标点击与方向键，逐帧记录位置）。

**验收场景**
1. **当** 点击图表、块公式、代码块、图片使其显示源码，**那么** 被点击块的顶部在屏幕上的位置保持不变（位移 ≤ 2px）。
2. **当** 点击其他位置使已展开的块收起，**那么** 被点击的内容位置保持不变。
3. **当** 用方向键、`Home`/`End` 移入或移出这些块，**那么** 按键前光标所在内容位置保持不变，光标始终可见。
4. **当** 在展开的源码中输入导致图表高度变化，**那么** 光标所在行位置保持不变。
5. **当** 拖动选择文字，**那么** 选区不被打乱。

### 用户故事 5 —— 现有功能全部保留 (P1)
作为 0.2.x 的用户，升级后所有已有功能照常可用，快捷键不变。

**独立测试**：执行规格 002 的验收清单与本规格的回归清单。

**验收场景**
1. **当** 使用菜单与快捷键（格式、标题 `Ctrl+1…6`/`Ctrl+0`、`Ctrl+T` 插入表格等全部 `KEYMAP` 项），**那么** 行为与 0.2.1 相同。
2. **当** 使用查找（`Ctrl+F`）、替换（`Ctrl+H`）、大纲跳转、文件树、专注模式（F8）、打字机模式（F9）、全屏、缩放、主题切换、字数统计，**那么** 行为与 0.2.1 相同；查找在源代码模式下同样可用。
3. **当** 粘贴或拖入图片，**那么** 保存到文档旁 `assets/` 并插入相对路径（未保存的新文档同 0.2.1）。
4. **当** 导出 HTML / PDF，**那么** 输出与 0.2.1 等效（排版、公式、图表、代码高亮、图片），完全离线。
5. **当** 文档未保存时关闭窗口或打开其他文件，**那么** 提示保存（与 0.2.1 相同）。

### 边界情况
- 超长文档（约 10000 行）：可打开、滚动流畅；离开可视区域的图表不渲染。
- 语法错误的 Mermaid 或公式：显示错误提示，不影响编辑。
- 图片路径不存在：显示占位，不报错弹窗。
- 一行中有多个行内公式、行内代码中出现 `$`：只按语法识别公式。
- 代码块中的 Markdown 语法不渲染。
- 表格单元格中的 `\|`、行内代码中的 `\|`（规格 004）：显示正确，原文不变。

## 需求

### 功能需求
- **FR-601** 编辑器内核替换为 CodeMirror 6，移除 Vditor 及其全部资源。
- **FR-602** 编辑内容即文件原文：除用户的编辑外，不对文本做任何规范化；保存时保持原换行符与 BOM。
- **FR-603** 撤销/重做只作用于改动处，按输入分组；切换文件时清空历史。
- **FR-604** 即时渲染覆盖用户故事 3 场景 1 列出的全部元素，光标进入元素时显示标记。
- **FR-605** 图表、块公式、代码块在光标进入时显示源码，渲染结果保留并实时更新。
- **FR-606** 点击与键盘移动引起的显示变化不使内容跳动（取代规格 003 的 FR-215、FR-217）。
- **FR-607** 源代码模式为不带排版的纯文本编辑，切换不改变文本。
- **FR-608** 0.2.1 的全部功能与快捷键保留（用户故事 5）。
- **FR-609** HTML / PDF 导出改用随包分发的渲染器，不依赖 Vditor。

### 非功能需求
- **NFR-601** 约 1150 行、15 个 Mermaid 图、15 个表格的文档：打开到可编辑 < 300ms（不含图表异步渲染）；撤销/重做 < 16ms；输入延迟 < 16ms。
- **NFR-602** 宪章 VII：安装包 ≤ 10MB，且不大于 0.2.1（3.55MB）；免安装版 ≤ 15MB。
- **NFR-603** 宪章 II：所有脚本、样式、字体随包分发，运行时无网络请求。
- **NFR-604** 冷启动时间与空闲内存不劣于 0.2.1（中位数 1.08s / 395MB，同一台机器测量）。

### 关键实体
- **Document**：路径、原文、换行符（LF/CRLF）、是否带 BOM、是否已修改。

## 成功标准
- **SC-601** 用户故事 1–5 的全部验收场景通过；规格 002 验收清单回归通过。
- **SC-602** 规格 005 中 Vditor 的 6 处“打开即改写”在新版本中全部消失。

## 澄清与假设
- 版本号 0.3.0。
- 不再自动重排表格源码的空格：表格源码保持用户写入的样子；表格结构操作（插入/删除行列等）后的排版由规格 003 决定。
- 规格 003 的用户故事 1（表格编辑）在本规格完成后基于新内核实现；用户故事 4（不跳动）由本规格的用户故事 4 取代；用户故事 2、3（分割线、收藏夹）与内核无关，不受影响。
- 设置文件、文件关联、安装方式不变。
- 不在范围内：新增 Vditor 之外的语法（如 PlantUML）、多标签页、拼写检查。
