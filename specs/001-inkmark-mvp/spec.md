# 功能规格：Inkmark MVP —— 本地 Markdown 查看与编辑器

**特性分支**: `001-inkmark-mvp` | **创建日期**: 2026-11-06 | **状态**: 已批准实现
**输入**: “参考 Typora 的主要特性（https://support.typora.io/）做一个 Windows 11 x64 可用的 Markdown 文件本地查看、编辑工具。”

## 背景
Typora 的核心价值是“无干扰的所见即所得 Markdown 写作”：输入即渲染、无工具栏、侧边栏大纲/文件树、专注/打字机模式、主题、数学公式与图表、图片粘贴、导出。Inkmark 以开源方式在 Windows 11 x64 上提供这些主要体验。

## 用户场景与测试

### 用户故事 1 —— 打开并查看 Markdown 文件 (P1)
作为用户，我在资源管理器中双击 / 拖入 / 通过菜单打开一个 `.md` 文件，立即看到渲染后的排版效果。

**独立测试**：打开 `samples/demo.md`，标题、列表、表格、代码块、数学公式、Mermaid 图、本地相对路径图片均正确渲染。

**验收场景**
1. **假设** 安装了 Inkmark，**当** 通过命令行参数 / 文件关联打开 `a.md`，**那么** 窗口显示其渲染内容，标题栏显示 `a.md - Inkmark`。
2. **假设** Inkmark 已运行，**当** 再次双击另一个 `.md`，**那么** 在已运行的窗口中打开（单实例），不启动第二个进程。
3. **假设** 文档含 `![](assets/x.png)`，**当** 打开，**那么** 图片按文档所在目录解析并显示。
4. **假设** 无网络，**当** 打开含公式 / Mermaid / 代码块的文档，**那么** 仍全部正确渲染。
5. **当** 把 `.md` 文件拖入窗口，**那么** 打开该文件。

### 用户故事 2 —— 即时渲染编辑与保存 (P1)
作为用户，我像 Typora 一样直接在渲染视图中编辑，用快捷键排版，并保存为纯 Markdown。

**验收场景**
1. **当** 输入 `## 标题` 回车，**那么** 立即渲染为二级标题；光标回到该块时显示 `##` 标记。
2. **当** 按 `Ctrl+S`，**那么** 内容以 UTF-8 纯 Markdown 写回原文件，标题栏的未保存标记 `•` 消失。
3. **当** 文档为新建未命名文件并按 `Ctrl+S`，**那么** 弹出另存为对话框。
4. **假设** 存在未保存修改，**当** 关闭窗口 / 打开其他文件 / 新建，**那么** 提示“保存 / 不保存 / 取消”，选择取消时不丢失任何内容。（打开其他文件、新建已不再触发此提示，见 008。）
5. **当** 使用 Typora 风格快捷键（见 FR-012），**那么** 执行对应排版。
6. **当** 按 `Ctrl+/`，**那么** 在即时渲染与源码模式之间切换，内容保持一致。

### 用户故事 3 —— 侧边栏：大纲与文件树 (P2)
**验收场景**
1. **当** 按 `Ctrl+Shift+L`，**那么** 显示/隐藏侧边栏。
2. **当** 切换到“大纲”页，**那么** 列出文档所有标题（按层级缩进），点击标题滚动到对应位置；编辑标题后大纲随之更新。
3. **当** 通过“打开文件夹”选择目录，**那么** “文件”页以树形列出其中的子目录与 Markdown 文件，点击文件即打开。

### 用户故事 4 —— 专注写作 (P2)
**验收场景**
1. **当** 按 `F8`，**那么** 进入专注模式：除光标所在块外其他内容变淡；再按退出。
2. **当** 按 `F9`，**那么** 进入打字机模式：光标所在行始终保持在窗口垂直中部附近。
3. **当** 按 `F11`，**那么** 切换全屏。
4. 状态栏实时显示字数（中文按字计、英文按词计）与字符数。

### 用户故事 5 —— 主题 (P2)
**验收场景**
1. **当** 在“主题”菜单选择 浅色 / 深色 / 跟随系统，**那么** 界面与正文、代码块配色随之切换，并在下次启动时保持。

### 用户故事 6 —— 图片插入 (P2)
**验收场景**
1. **假设** 当前文件已保存于磁盘，**当** 粘贴或拖入图片，**那么** 图片被复制到文档同目录的 `assets/` 下，并插入相对路径 `![](assets/<文件名>)`。
2. **假设** 当前文件未保存，**当** 粘贴图片，**那么** 图片保存到系统临时目录并以绝对路径插入。

### 用户故事 7 —— 查找替换 (P3)
**验收场景**
1. **当** 按 `Ctrl+F`，**那么** 出现查找栏，输入关键字高亮匹配，回车跳到下一个。
2. **当** 按 `Ctrl+H`，**那么** 出现替换输入框，可“全部替换”。

### 用户故事 8 —— 导出 (P3)
**验收场景**
1. **当** 选择“导出 → HTML”，**那么** 生成单个可独立打开的 `.html`，样式完整。
2. **当** 选择“导出 → PDF”，**那么** 生成排版正确的 `.pdf`（含公式、图表）。

### 用户故事 9 —— 最近文件与链接 (P3)
**验收场景**
1. “文件 → 最近打开”列出最近 10 个文件，点击即打开；不存在的文件被移除。
2. **当** `Ctrl+单击` 文档中的链接，**那么** http(s) 链接在系统浏览器打开；指向本地 `.md` 的相对链接在 Inkmark 中打开。

### 边界情况
- 打开非 UTF-8 或超大文件（>5MB）：按 UTF-8 读取；超大文件仍可打开（性能不作保证）。
- 文件被外部删除后保存：按原路径重新创建。
- 打开不存在的路径：提示错误，保留当前文档。

## 需求

### 功能需求
- **FR-001** 支持打开 `.md` `.markdown` `.mdown` `.txt` 文件；支持命令行参数、文件关联、拖放、菜单打开。
- **FR-002** 单实例：第二次启动时把文件交给已运行实例。
- **FR-003** 默认即时渲染（IR）编辑；`Ctrl+/` 切换源码模式。
- **FR-004** 渲染 GFM（表格、任务列表、删除线、自动链接）、脚注、KaTeX 数学公式、Mermaid/流程图、代码高亮；全部离线。
- **FR-005** 新建、保存、另存为；保存为 UTF-8；原子写入。
- **FR-006** 未保存修改提示（标题栏 `•`）与关闭/切换确认。
- **FR-007** 侧边栏：大纲、文件树；`Ctrl+Shift+L` 显示隐藏，`Ctrl+Shift+1` 大纲，`Ctrl+Shift+3` 文件树。
- **FR-008** 专注模式 F8、打字机模式 F9、全屏 F11。
- **FR-009** 状态栏字数与字符数。
- **FR-010** 浅色 / 深色 / 跟随系统主题，持久化。
- **FR-011** 图片粘贴/拖入保存到 `./assets/` 并插入相对路径；相对路径图片正确显示。
- **FR-012** Typora 风格快捷键：`Ctrl+1..6` 标题、`Ctrl+0` 段落、`Ctrl+B` 粗体、`Ctrl+I` 斜体、`Ctrl+U` 下划线、`Alt+Shift+5` 删除线、``Ctrl+Shift+` `` 行内代码、`Ctrl+K` 链接、`Ctrl+Shift+Q` 引用、`Ctrl+Shift+[` 有序列表、`Ctrl+Shift+]` 无序列表、`Ctrl+Shift+X` 任务列表、`Ctrl+Shift+K` 代码块、`Ctrl+Shift+M` 公式块、`Ctrl+T` 表格、`Ctrl+Shift+-` 分隔线。
- **FR-013** 查找（`Ctrl+F`）与替换（`Ctrl+H`，全部替换）。
- **FR-014** 导出 HTML、PDF。
- **FR-015** 最近打开文件（10 个），持久化。
- **FR-016** 外部链接在系统浏览器打开；`Ctrl+单击` 本地 md 链接在应用内打开；窗口不可被导航。
- **FR-017** 界面语言：简体中文。
- **FR-018** 提供 Windows x64 NSIS 安装包（注册 `.md` 文件关联）与便携版。

### 非功能需求
- **NFR-001** 冷启动到可编辑 < 3 秒（普通 PC）。
- **NFR-002** 无网络环境下全部功能可用。
- **NFR-003** 遵守宪章第 V 条安全默认。

### 关键实体
- **Document**：路径（可空）、Markdown 文本、已保存文本快照（用于判断 dirty）。
- **Settings**：主题、最近文件、侧边栏可见性与当前页、最近打开的文件夹。

## 成功标准
- **SC-001** 用户故事 1–6 的全部验收场景通过。
- **SC-002** 生成的安装包可在干净的 Windows 11 x64 上安装并打开 `.md`。

## 澄清与假设
- 采用单窗口模式：打开新文件替换当前文档（经未保存确认）。多窗口、多标签不在 MVP 范围。（已由 [008-multi-tabs](../008-multi-tabs/spec.md) 取代：打开文件改为新标签，未保存确认只在关闭标签或窗口时出现。）
- 不提供自动保存、云同步、插件系统、自定义 CSS 主题文件、Word/LaTeX 导出（超出 MVP）。
- 替换功能作用于 Markdown 源文本。
- 安装包不做代码签名（Windows SmartScreen 可能提示，属已知限制）。
