> **内核变更**：0.3.0 起编辑内核为 CodeMirror 6（规格 [006](../006-codemirror-core/spec.md)）。“点击时内容不跳动”已由 006 的用户故事 4 实现，从本规格移除。

## 背景

- **表格**：0.2.0 只能用 `Ctrl+T` 插入固定模板，增删行列只能改源码。Typora 提供表格工具条（调整大小、对齐）、右键菜单、快捷键与拖动排序，是其主要卖点之一。
- **侧边栏**：宽度固定 260px，长文件名被截断、宽屏浪费空间。
- **收藏夹**：常用文档分散在不同目录，每次都要“打开文件夹”再逐级展开。

## 用户场景与测试

### 用户故事 1 —— 可视化编辑表格 (P1)
作为用户，我在即时渲染模式下直接用鼠标和快捷键调整表格结构，不需要手写 `|` 和 `---`。

**独立测试**：在空文档中插入 3×3 表格，完成增删行列、对齐、移动、调整大小、删除表格，每一步后 Markdown 源码正确且可 `Ctrl+Z` 撤销；在约 1000 行的长文档中重复，确认只有当前表格被更新。

**验收场景**
1. **当** 按 `Ctrl+T` 或菜单“段落 → 表格”，**那么** 弹出尺寸选择器（网格 + 行列数输入框），确认后在光标处插入对应大小的空表格，光标位于第一个表头单元格。
2. **当** 光标在表格内，**那么** 表格上方出现工具条：调整大小、当前列左对齐/居中/右对齐、删除表格、更多（同右键菜单）。光标离开表格时工具条消失。
3. **当** 点击工具条的“调整大小”，**那么** 弹出与插入时相同的尺寸选择器，预选当前大小；确认后在右侧/下方增删列和行，已有内容保留（被删除的行列内容丢弃）。
4. **当** 在单元格上点击右键，**那么** 显示菜单：上方/下方插入行、左侧/右侧插入列、上移/下移行、左移/右移列、删除行、删除列、左对齐/居中/右对齐、删除表格。不可用的项置灰（如表头行不能上移、不能删除表头、只剩一列时不能删除列）。
5. **当** 光标在单元格中按 `Ctrl+Enter`，**那么** 在当前行下方插入空行，光标移到新行同一列。
6. **当** 按 `Ctrl+Shift+Backspace`，**那么** 删除当前行（表头除外）。
7. **当** 按 `Tab` / `Shift+Tab`，**那么** 光标移到下一个/上一个单元格；在最后一个单元格按 `Tab` 时在末尾新增一行。
8. **当** 鼠标悬停在某行，**那么** 该行左侧出现拖动手柄；悬停在某列，**那么** 该列上方出现拖动手柄。拖动手柄到新位置松开，**那么** 整行/整列移动到该位置，拖动过程中显示插入位置指示线。
9. **当** 执行以上任一操作后按 `Ctrl+Z`，**那么** 表格恢复到操作前的状态；`Ctrl+Y` 重做。
10. **当** 在含多个图表的长文档中执行表格操作，**那么** 只有当前表格更新，其他内容不闪烁、不重新渲染，滚动位置不变。
11. **当** 执行表格操作后查看源码模式，**那么** 表格源码按列对齐排版（中日韩字符按 2 个宽度计算），对齐方式写在分隔行（`:---`、`:---:`、`---:`）。

### 用户故事 2 —— 拖动调整侧边栏宽度 (P1)
**验收场景**
1. **当** 鼠标移到侧边栏与内容区的分界处，**那么** 光标变为左右调整形状，并在短暂停留后显示一条高亮分割线。
2. **当** 按住分割线左右拖动，**那么** 侧边栏宽度实时跟随，范围 180px 至 min(560px, 窗口宽度的一半)；拖动时正文不被选中。
3. **当** 拖到小于收起阈值（120px）后松开，**那么** 侧边栏收起；拖回阈值以上则在拖动中恢复显示。
4. **当** 侧边栏已收起，**那么** 窗口左边缘保留可拖动的分割线，向右拖动即可展开；`Ctrl+Shift+L` 与菜单也能展开，展开后恢复收起前的宽度。
5. **当** 双击分割线，**那么** 宽度恢复默认值 260px。
6. **当** 分割线获得键盘焦点，**那么** `←`/`→` 每次调整 16px，`Enter` 收起/展开。
7. **当** 重启应用，**那么** 侧边栏宽度与展开状态保持不变。

### 用户故事 3 —— 收藏文件与文件夹 (P1)
**验收场景**
1. 侧边栏新增“收藏”页，与“文件”“大纲”并列；`Ctrl+Shift+2` 切换到该页。
2. **当** 鼠标悬停在文件树的文件或文件夹（含顶部的根文件夹名）上，**那么** 行尾出现 ☆ 按钮，点击后加入收藏并变为 ★；再次点击取消收藏。
3. **当** 在文件树或收藏列表上点击右键，**那么** 菜单提供“添加到收藏”/“从收藏中移除”。
4. **当** 选择菜单“文件 → 收藏当前文件”，**那么** 当前已保存的文件加入收藏（已收藏则移除，菜单文字相应变化）；未保存的新文档该项不可用。
5. 收藏列表按添加顺序排列（新收藏追加在末尾）；每项显示图标（文件夹/文件）、名称，名称后以浅色显示所在文件夹名，悬停提示完整路径；当前打开的文件高亮。
6. **当** 点击收藏的文件，**那么** 打开该文件（有未保存修改时先确认）。**当** 点击收藏的文件夹，**那么** 在“文件”页以该文件夹为根打开并切换到“文件”页。
7. **当** 按住收藏项拖动（移动超过 4px 开始），**那么** 显示插入位置指示线，松开后收藏项移动到新位置；顺序立即保存。
8. **当** 收藏项获得键盘焦点，**那么** `Alt+↑`/`Alt+↓` 调整顺序，`Delete` 移除，`Enter` 打开。
9. **当** 鼠标悬停在收藏项，**那么** 行尾出现 × 按钮，点击即移除（无需确认）。
10. **当** 收藏的路径已不存在，**那么** 该项变淡并在悬停提示中注明“不存在”，点击不打开，仍可移除或排序。
11. **当** 没有任何收藏，**那么** 显示简短的空状态说明：如何添加收藏。
12. **当** 重启应用，**那么** 收藏及其顺序保持不变。

### 边界情况
- 表格单元格中含 `\|` 转义（包括行内代码中）：表格操作后保持为转义竖线，不被误拆分。
- 位于引用块或列表中的表格：操作后保留每行的前缀（如 `> `、缩进）。
- 源码模式下：不显示表格工具条与拖动手柄；表格快捷键不生效（与 Typora 一致）。
- 同一路径重复收藏：不会重复添加。
- 收藏的文件被重命名或移动：视为不存在（不跟踪）。
- 窗口缩小导致侧边栏宽度超过上限：自动收窄到上限。

## 需求

### 功能需求
- **FR-201** 插入表格时可选择行列数（网格选择最大 10×10，输入框最大 50×20）。
- **FR-202** 光标在表格内时显示表格工具条：调整大小、当前列对齐（左/中/右）、删除表格、更多。
- **FR-203** 单元格右键菜单：插入行（上/下）、插入列（左/右）、移动行（上/下）、移动列（左/右）、删除行/列、列对齐、删除表格；不可用项置灰。
- **FR-204** 表格快捷键：`Ctrl+Enter` 下方插入行，`Ctrl+Shift+Backspace` 删除行，`Tab`/`Shift+Tab` 在单元格间移动，最后一个单元格 `Tab` 新增行。
- **FR-205** 拖动行/列手柄移动整行/整列。
- **FR-206** 表格操作可撤销；操作后表格源码按列对齐排版；保留单元格内容与行内格式。
- **FR-207** 表格至少保留表头行、一行数据与一列。
- **FR-216** 表格操作只更新当前表格：文档中的其他内容（图表、公式、图片、其他表格）不重新渲染，滚动位置不变。
- **FR-208** 侧边栏与内容区之间的分割线：拖动调整宽度（180px 至 min(560px, 窗口宽度 50%)）、拖到 120px 以下收起、收起后可从左边缘拖出、双击恢复 260px、键盘可操作。
- **FR-209** 侧边栏宽度与展开状态持久化。
- **FR-210** 收藏夹：收藏文件与文件夹，按添加顺序排列，可拖动或用键盘调整顺序，可移除，持久化。
- **FR-211** 添加收藏的入口：文件树悬停 ☆ 按钮、右键菜单、“文件 → 收藏当前文件”。
- **FR-212** 点击收藏的文件打开文件；点击收藏的文件夹在文件树中以其为根打开。
- **FR-213** 标出已不存在的收藏项。
- **FR-214** 侧边栏“收藏”页，`Ctrl+Shift+2` 切换。

### 非功能需求
- **NFR-201** 宪章 VII：安装包仍 ≤ 10MB；不引入新的第三方依赖。
- **NFR-202** 在约 1000 行、含 15 个表格和 15 个 Mermaid 图的文档中，一次表格操作（含记录撤销）< 50ms，且操作期间其他块的 DOM 节点保持不变（可用节点引用比对验证）。
- **NFR-203** 新增界面元素支持深色/浅色主题，可用键盘操作，有可读的提示文字（`title`/`aria-label`）。

## 澄清与假设
- 表格单元格只支持行内内容，不支持合并单元格（GFM 限制，与 Typora 一致）。
- 列对齐写入 Markdown 分隔行，而不是 HTML 样式。
- 不跟踪被重命名或移动的收藏项。
- 收藏夹不分组、不支持重命名显示名称（保持简单）。
- 侧边栏分割线参考 Claude Desktop 与 VS Code 的通行做法：悬停高亮、拖动调整、拖过阈值收起、双击复位。
- 表格结构操作（增删、移动、对齐、调整大小）后，该表格的源码按列对齐重排；只编辑单元格文字时不重排（规格 006 FR-602）。
