# 功能规格：使用指南

**特性分支**: `013-user-guide` | **创建日期**: 2026-11-10 | **状态**: 已批准
**输入**: 为 Inkmark 写一份配套的帮助手册：内置、离线可用的 Markdown 使用指南，重点说明图片文件夹、换电脑、分享与旧文档迁移等不看说明难以理解的功能。

## 用户场景与测试

### 用户故事 1 —— 打开使用指南 (P1)

用户遇到不会用的功能时，在软件内就能打开使用指南，不需要联网。

**独立测试**：分别在安装版和免安装版中，断网后从“帮助”菜单和起始页打开使用指南。

**验收场景**

1. **当** 选择“帮助 → 使用指南”，**那么** 在新标签中打开使用指南；已经打开时切换到该标签。
2. **当** 在起始页查看“开始”区域，**那么** 有“使用指南”入口。
3. **假设** 使用免安装版且没有网络，**当** 打开使用指南，**那么** 正常打开，图片正常显示。
4. **当** 查看使用指南开头，**那么** 注明适用的 Inkmark 版本。
5. **当** 在使用指南中输入、粘贴或拖入内容，**那么** 内容不变；标签与状态栏标明“只读”；可以选择、复制文字和使用图片右键菜单。
6. **当** 关闭使用指南标签或退出程序，**那么** 不提示保存。
7. **当** 打开使用指南后查看“最近打开”列表，或重新启动程序，**那么** 使用指南不在列表中，也不被恢复为标签。

### 用户故事 2 —— 指南内容 (P1)

用户能在指南中找到每个主要功能的用法和常见问题的解决办法。

**独立测试**：按指南的目录逐节操作，核对描述与软件实际一致。

**验收场景**

1. **当** 查看指南，**那么** 依次包含：快速上手（打开、编辑、即时渲染与源代码模式）；多标签与起始页；图片（粘贴与拖入、图片文件夹、换电脑、分享给别人、旧文档迁移、右键菜单）；导出（HTML、PDF、可分享副本）；快捷键（指向 `F1`，不重复列出）；常见问题；数据与隐私。
2. **当** 查看“常见问题”，**那么** 至少回答：图片不显示怎么办；把文档发给别人后对方看不到图片怎么办；换电脑后图片怎么找回；缩放后如何恢复原大小；关闭程序时为什么会提示保存。
3. **当** 查看“数据与隐私”，**那么** 说明：完全离线、不收集数据；设置、图片文件夹的位置；卸载时图片和设置会保留（文档仍在引用这些图片），以及不再使用时如何手动删除；Inkmark 不会修改你没有编辑的文档。
4. **当** 指南提到菜单路径（如“文件 → 图片文件夹…”）或快捷键，**那么** 与软件中的实际名称一致。
5. **当** 指南含示意图片，**那么** 图片随指南一起分发，离线显示。

### 用户故事 3 —— 示例文档在免安装版中可用 (P2)

免安装版用户也能打开 Markdown 示例文档。

**独立测试**：在只有一个 `.exe` 的免安装版中打开“帮助 → Markdown 示例文档”。

**验收场景**

1. **当** 在免安装版中选择“帮助 → Markdown 示例文档”，**那么** 正常打开，示例中的图片正常显示。
2. **当** 在安装版中选择同一菜单，**那么** 正常打开，可以编辑练习。
3. **假设** 上次打开时修改过示例文档，**当** 再次从菜单打开，**那么** 恢复为原始内容；已打开且有未保存修改时，先按现有规则询问是否保存。
4. **当** 打开示例文档后查看“最近打开”列表，或重新启动程序，**那么** 示例文档不在列表中，也不被恢复为标签。

### 用户故事 4 —— 不留下多余文件 (P2)

使用指南和示例文档不在用户能看到的位置产生文件，也不越积越多。

**独立测试**：多次打开指南和示例文档后，检查释放的文件；安装版卸载时勾选“删除应用程序数据”后再检查。

**验收场景**

1. **假设** 从未打开过使用指南和示例文档，**那么** 不释放任何文件。
2. **当** 多次打开，**那么** 只有程序数据目录下固定文件夹中的一份文件，每次覆盖。
3. **当** 卸载时勾选“删除应用程序数据”，**那么** 释放的指南与示例文件被删除；图片文件夹与设置保留。
4. **假设** 从 0.6.0 或更早版本升级（安装目录中有旧版的 `samples` 文件夹），**当** 升级后再卸载，**那么** 安装目录中不残留 `samples`，安装目录被删除。

### 用户故事 5 —— 指南与软件保持一致 (P2)

维护者修改功能后，不会忘记同步指南。

**独立测试**：把指南中的某个菜单名改成不存在的名称，运行测试。

**验收场景**

1. **假设** 指南中提到的菜单路径在软件中不存在，**当** 运行自动测试，**那么** 测试失败并指出该处。
2. **当** 查看规格模板中的验收清单，**那么** 包含“检查使用指南是否需要更新”一项。

### 边界情况

- 只读的使用指南上使用“另存为”：保存为用户选择的新文件，新文件可正常编辑。
- 程序数据目录无法写入：提示原因，不打开。
- 升级 Inkmark 后打开：显示新版本的指南。
- 示例文档中的图片：释放到同一固定文件夹，不进入用户的图片文件夹。

## 需求

### 功能需求

- **FR-1301** 必须提供使用指南，以 Markdown 编写，随程序分发，通过“帮助 → 使用指南”和起始页打开。
- **FR-1302** 使用指南与示例文档（含图片）必须内置在程序中，首次打开时才释放到程序数据目录下的固定文件夹（随“删除应用程序数据”一并清除的位置），每次打开覆盖；安装版与免安装版行为一致。
- **FR-1303** 每次从菜单打开都恢复为当前版本的内容。
- **FR-1304** 使用指南以只读方式打开：不能编辑，不提示保存，标明“只读”；可另存为。
- **FR-1305** 使用指南与示例文档不加入“最近打开”，不参与标签恢复。
- **FR-1306** 指南内容覆盖用户故事 2 列出的章节与常见问题，界面名称与软件一致。
- **FR-1307** 自动测试必须检查指南中提到的菜单路径都存在于菜单中。
- **FR-1308** 规格模板的验收清单增加“检查使用指南是否需要更新”。
- **FR-1309** 安装新版后删除安装目录中旧版留下的 `samples` 文件夹。

### 非功能需求

- **NFR-1301** 不新增依赖；安装包体积增加不超过 200KB（宪章 VII）。
- **NFR-1302** 离线可用，不包含任何网络资源（宪章 II）。

## 成功标准

- **SC-001** 用户故事 1–5 的验收场景全部通过。

## 澄清与假设

- 指南面向普通用户，用简体中文书写，控制在几页之内；开发与贡献说明仍在 README 和 CONTRIBUTING 中。
- 卸载程序只在勾选“删除应用程序数据”时删除以应用标识命名的数据目录；图片文件夹（默认 `%LOCALAPPDATA%\inkmark-images`）与设置（`%APPDATA%\Inkmark`）不在其中，卸载后保留。这是按 Tauri 安装程序模板推断的结论，plan 阶段实际安装、卸载验证。
- 安装方式保持“仅当前用户”：默认目录 `%LOCALAPPDATA%\Inkmark`，可修改，覆盖安装时自动定位到当前安装目录。评审中讨论过默认装到 `C:\Program Files`，因需改为所有用户安装、每次安装都请求管理员权限，未采用。
- 不在本规格范围：多语言版本、在线文档网站、视频教程、应用内的交互式引导、卸载时删除图片文件夹。
