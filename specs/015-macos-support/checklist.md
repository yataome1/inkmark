## 手动验证步骤

准备：在仓库中执行 `npm run dist:mac`，安装文件在 `src-tauri/target/universal-apple-darwin/release/bundle/dmg/`。验证前退出所有 Inkmark（含 `npm start` 的开发版）。

1. **安装与首次打开（US1-1、US1-5）**：给 dmg 加上下载隔离属性以模拟从网上下载：`xattr -w com.apple.quarantine "0081;00000000;Safari;" <dmg 路径>`。打开 dmg，把 Inkmark 拖进“应用程序”，从启动台打开：应提示无法验证开发者；到“系统设置”的“隐私与安全性”点“仍要打开”后正常启动；退出再打开不再提示。
2. **打开文件（US1-2、US1-3）**：程序未运行时，把 `.md` 文件拖到程序坞图标上 → 打开该文件；程序运行时再拖一个 → 同一窗口新标签。选中一个 `.md` 文件按 `⌘I`，“打开方式”选 Inkmark 并“全部更改…”，之后双击 `.md` 用 Inkmark 打开。
3. **快捷键（US2-1、US2-2）**：在文档中试 `⌘S` `⌘/` `⌘W` `⇧⌘T` `⌘B`（只加粗一次，不会加粗后又取消）`⌘Z` `⇧⌘Z` `⌥⌘F`（替换）`⌃⌘1`（大纲）`⌃Tab`（切换标签）`⌃1`（第一个标签）`⇧⌘/`（快捷键列表）；在查找框中输入文字后 `⌘Z` 只撤销查找框；`⌘+单击`链接；`⌘+滚轮`与双指捏合缩放。快捷键列表、菜单、右键菜单中的按键都是 ⌘ 符号且与实际一致。
4. **菜单栏与系统快捷键（US2-3、US2-5）**：第一个菜单是“Inkmark”，含关于、隐藏 Inkmark、隐藏其他、全部显示、退出 Inkmark ⌘Q；“窗口”菜单含最小化、缩放；菜单标题没有 `(&F)` 这类字样；“文件”菜单中没有“退出”，“帮助”中没有“关于”。`⌃⌘F` 进入 / 退出全屏；`⌘H` 隐藏程序、`⌘M` 最小化、``⌘` `` 切换窗口与其他应用相同。“关于”显示 macOS 版本与 WebKit 版本。
5. **关闭与退出（US2-4、边界）**：打开文档并修改不保存 → 点红色关闭按钮 → 询问保存；选“取消”窗口保留；选“不保存”窗口隐藏，程序仍在程序坞；点程序坞图标 → 显示起始页。再打开文档修改 → `⌘Q` → 询问。修改后按 `⌘M` 最小化，在程序坞右键“退出” → 窗口恢复并询问（不能直接退出）。`⌘H` 后同样检查。
6. **跨平台文档（US3-2）**：把 Windows 上编辑过、含相对路径图片与图片文件夹图片的文档拷到 Mac，用“文件 → 图片文件夹…”指向拷来的图片文件夹 → 图片都显示；在 Mac 上粘贴一张图片并保存，拷回 Windows 打开 → 正常（图片文件夹同样拷回）。
7. **导出 PDF（US3-3）**：用“帮助 → Markdown 示例文档”分别在 Windows 与 Mac 上“文件 → 导出 → PDF…”，对比纸张（Letter）、边距、分页、公式、Mermaid 图表、代码高亮。
8. **复制图片文件（US3-4）**：在图片上右键“复制图片文件”，到访达中 `⌘V` → 得到图片文件；右键“在访达中显示”打开访达并选中该文件。
9. **主题（US3-5）**：主题设为“跟随系统”，在“系统设置 → 外观”中切换浅色 / 深色 → Inkmark 随之切换。

## 实现中发现并已修复的问题

- macOS 上 `tauri dev` 的页面来自 `http://127.0.0.1:1430`，被禁止导航拦截，开发版页面不加载 → 调试构建放行该地址
- 冷启动时访达在 setup 之前送来要打开的文件，取 `AppState` 导致发布版崩溃 → 先暂存，setup 时并入
- 程序坞“退出”以窗口是否可见判断，`⌘H` / `⌘M` 后会跳过未保存确认 → 改为判断窗口是否已由“关闭”隐藏
- 右键菜单（图片、正文、表格、标签）选择任一项后，编辑区跳回顶部、偶尔变成空白：关闭菜单时 `focus()` 在 WebKit 中滚动到光标处 → 改为 `preventScroll`（用户验收发现）
- 引用 `⇧⌘Q`（系统退出登录）、行内代码 ``⇧⌘` ``（切换窗口）、删除线 `⌥⇧5`（输入特殊字符）在 Mac 上冲突 → 加入例外表
