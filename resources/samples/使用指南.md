# Inkmark 使用指南

适用于 Inkmark {{version}}。本指南为只读，想保留一份可以编辑的副本，请用“文件 → 另存为…”。按 `F1` 查看全部键盘快捷键。

## 快速上手

- **打开**：“文件 → 打开…”（`Ctrl+O`），或把 `.md` 文件拖到窗口中。安装版会把 `.md` 文件关联到 Inkmark，可以在资源管理器的右键“打开方式”中选择 Inkmark。
- **编辑**：Inkmark 默认是即时渲染：标题、列表、表格、公式、图表都直接显示成排版后的样子；把光标移进去，就会露出这一处的 Markdown 原文，可以直接修改。
- **源代码模式**：“视图 → 源代码模式”（`Ctrl+/`）显示整篇原文，再按一次回到即时渲染。
- **保存**：`Ctrl+S`。Inkmark 只保存你写的原文，打开再保存不会改动你没有编辑过的地方。
- **想看各种写法的效果**：打开“帮助 → Markdown 示例文档”，可以随意修改练习，下次打开会恢复原样。

## 多标签与起始页

- 每个文件在单独的标签中打开，同一个文件只有一个标签。有未保存修改的标签，右侧的关闭按钮显示为圆点。
- 关闭标签：点 `×`、鼠标中键或 `Ctrl+W`；误关了可以用“文件 → 重新打开关闭的标签”（`Ctrl+Shift+T`）。
- 关闭全部标签后显示起始页：新建、打开、最近文件和收藏都在这里。
- 下次启动时会恢复上次打开的标签。不需要时，在“文件 → 启动时恢复上次的标签”中关闭。

## 图片

### 粘贴与拖入

截图后在文档中按 `Ctrl+V`，或把图片文件拖进编辑区，图片会被保存到 **图片文件夹**，文档里写入这张图片的完整路径。

- 图片按内容命名（一串字母和数字），同一张图片只保存一份。
- 因为写的是完整路径，把文档移动到别的文件夹，图片照样显示。

### 图片文件夹

默认位置是 `%LOCALAPPDATA%\inkmark-images`。在“文件 → 图片文件夹…”中可以：

- 查看当前位置、打开这个文件夹；
- 更改到其他位置，例如数据盘或同步盘，并选择是否把已有图片复制过去；
- 恢复默认位置。

### 换电脑

把文档和图片文件夹一起拷到新电脑（或放在同步盘中），在新电脑上用“文件 → 图片文件夹…”指向拷过来的图片文件夹。打开文档时，如果原路径找不到图片，Inkmark 会自动到当前图片文件夹中按文件名找回，不会改动文档。

### 发给别人

直接发送 `.md` 文件，对方的电脑上没有你的图片。请用“文件 → 导出 → 可分享副本…”：Inkmark 会把文档和用到的图片一起导出，图片放在旁边的 `文件名.assets` 文件夹中，并改成相对路径。把导出的文档和这个文件夹一起发送即可。原文档不会被修改。

### 旧文档迁移

旧文档如果把图片放在自己旁边（例如 `assets/` 文件夹），照样可以显示，不需要处理。想统一放进图片文件夹时，打开该文档，选择“文件 → 收入图片文件夹”：图片被复制进图片文件夹，文档中的地址改为新位置。这一步可以用 `Ctrl+Z` 撤销，原来的图片不会被删除，确认无误后再保存。

### 图片右键菜单

在编辑区的图片上单击右键，可以复制图片、复制图片文件（粘贴到聊天软件或文件夹中得到原文件）、图片另存为、复制图片地址、在资源管理器中显示、用默认程序打开。

## 导出

- “文件 → 导出 → HTML…”：生成一个网页文件。
- “文件 → 导出 → PDF…”：生成 PDF 文件。
- “文件 → 导出 → 可分享副本…”：文档和图片一起导出，适合发给别人，见上文“发给别人”。

## 快捷键

按 `F1` 或选择“帮助 → 键盘快捷键”查看完整列表。菜单中的每一项也标出了对应的快捷键。

## 常见问题

**图片不显示怎么办？**

- 图片文件被移动或删除了：在图片上右键，“复制图片地址”可以看到文档中写的位置，找到图片后放回原处；如果是 Inkmark 粘贴保存的图片，也可以把它放进当前的图片文件夹。
- 换了电脑：见“换电脑”，用“文件 → 图片文件夹…”指向拷过来的图片文件夹。
- 网络图片：Inkmark 完全离线，不加载网络上的图片。

**把文档发给别人后，对方看不到图片？**

文档中的图片保存在你自己电脑上的图片文件夹中。请用“文件 → 导出 → 可分享副本…”导出后再发送，并连同 `文件名.assets` 文件夹一起发送。

**换电脑后，图片怎么找回？**

把旧电脑上的图片文件夹拷到新电脑，然后用“文件 → 图片文件夹…”指向它。

**缩放后如何恢复原大小？**

按 `Ctrl+Shift+9`，或选择“视图 → 实际大小”。按住 `Ctrl` 滚动鼠标滚轮可以放大缩小，缩放比例会在下次启动时保留。

**关闭程序时为什么会提示保存？**

有标签中存在还没有保存的修改。可以选择保存、不保存，或取消关闭回去检查。“文件 → 全部保存”（`Ctrl+Alt+S`）可以一次保存所有修改。

## 数据与隐私

- Inkmark 完全离线运行，不联网、不收集任何数据。只有当你点击“帮助”菜单中的更新日志、报告问题等链接时，才会用浏览器打开对应网页。
- Inkmark 不会修改你没有编辑的文档；保存时先写临时文件再替换，避免写到一半损坏原文件。

Inkmark 在你的电脑上保存以下数据：

| 内容 | 位置 |
|---|---|
| 粘贴、拖入的图片 | 图片文件夹，默认 `%LOCALAPPDATA%\inkmark-images` |
| 设置（主题、最近文件、收藏、标签、缩放等） | `%APPDATA%\Inkmark\settings.json` |
| 程序数据（本指南与示例文档的副本、浏览器内核缓存） | `%LOCALAPPDATA%\io.github.yataome1.inkmark` |

**卸载时**：请先关闭 Inkmark。只有在卸载界面勾选“删除应用程序数据”，才会删除程序数据。图片文件夹和设置始终保留，因为你的文档仍在引用这些图片，重新安装后可以直接使用。如果确定不再使用 Inkmark，也不再需要文档中的图片，可以手动删除上表中的文件夹。
